# Security policy

## Supported versions

The `py-vX.Y.Z` tags are the only contract. Fixes land on the newest tag; older tags are not
backported. `main` is a working branch and carries no guarantee at all.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository — **Security → Report a
vulnerability**. That is the only channel; there is no published email address, deliberately.

I make no commitment about response time. This is a personal library maintained for my own
applications; see [CONTRIBUTING.md](CONTRIBUTING.md) for what that means.
