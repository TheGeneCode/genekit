# Contributing

I am not taking contributions. This file exists because GitHub links it from the page where you would
open a pull request, and that is the one moment worth catching you before you spend the time.

## Why not

genekit is a decisions library, not a utility package. Admission is governed by
[CHARTER.md](CHARTER.md): a capability enters only after three independent sightings across at least
two repos, each recorded in [ledger/CANDIDATES.md](ledger/CANDIDATES.md), and every public symbol
clears a quality gate before any tag is cut. The evidence a promotion requires is evidence drawn from
my own codebases, and those are private. A pull request adding a module therefore cannot satisfy the
charter no matter how good the code is — the rule of three is not a formality I could waive for a good
patch, it is the whole mechanism keeping this repo from becoming the grab-bag it was built not to be.

That is a statement about the process, not about your code.

## Issues and pull requests

Issues, Discussions, Wiki and Projects are disabled. Pull requests cannot be disabled on a public
repository, so one can still be opened; it will be closed without review. Forking is the intended
answer — the license is MIT and asks nothing of you beyond keeping the notice. If something here is
broken, fix it in your fork; I will find the same bugs you do, because every consumer of this library
is mine.

## Security

One exception. If you find a genuine vulnerability, use GitHub's private vulnerability reporting on
this repository — **Security → Report a vulnerability**. That is the only channel; there is no
published email, deliberately. I make no commitment about response time.
